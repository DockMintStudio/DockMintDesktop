# DockMint Desktop

**A simple, customizable desktop workspace for your projects.**

DockMint Desktop helps you keep your projects, files, tasks, notes, and favorite applications organized in one place. Create separate workspaces for different activities, customize your layout, and keep the tools you use most within easy reach.

## 📥 Download DockMint

**[Go to DockMint Desktop Releases](https://github.com/DockMintStudio/DockMintDesktop/releases)**

Follow these steps to download and install DockMint on Windows:

1. Open the [Releases page](https://github.com/DockMintStudio/DockMintDesktop/releases).
2. Select the latest available release.
3. Scroll down to the **Assets** section.
4. Download the DockMint Windows installer, usually named something like `DockMint-Setup-0.1.0.exe`. The exact filename may vary by version.
5. Wait for the download to finish, then open the downloaded `.exe` file.
6. Follow the installer instructions.
7. Once installation is complete, launch DockMint from the Windows Start menu or your desktop shortcut, if one was created.

**Can't find a release?** If the Releases page doesn't contain an installer yet, a release hasn't been published with a downloadable build. Check back later.

Only download DockMint from the official repository and its Releases page.

## ✨ Features

- **Workspaces** — Keep different projects and activities separated and organized.
- **File and folder shortcuts** — Access existing files and folders from your workspace.
- **Task management** — Track your next steps and mark tasks complete.
- **Quick Notes** — Keep useful reminders and ideas close at hand.
- **Quick Launch** — Access supported application shortcuts and frequently used tools.
- **Customization** — Personalize the appearance and layout using the options available in your version.

## 🚀 Getting Started

### Create a workspace

Create a workspace for each area you want to organize. For example, use separate workspaces for school, game development, or personal projects.

### Add files and folders

Add shortcuts to files and folders you already use. This lets you access them from DockMint without needing to reorganize your existing folders.

Removing a shortcut from DockMint is not the same as deleting the original file.

### Manage tasks and notes

Use the Tasks panel to keep track of assignments, project milestones, bugs, and other things you need to do. Use Quick Notes for ideas, reminders, and useful information.

### Set up Quick Launch

Add supported application shortcuts to make your frequently used programs easier to open. Only use executables and shortcuts from sources you trust.

### Customize your workspace

Explore the available appearance, accent color, layout, and panel settings to make DockMint work the way you prefer.

## 🔒 Files and Privacy

DockMint is designed to organize access to your existing files and applications rather than replace your file system.

- Your original files remain in their existing locations.
- Removing a saved shortcut should not delete the original file.
- Back up important files and workspace information regularly.
- Workspace data and settings may be stored locally on your computer.

## 🛠️ Troubleshooting

**DockMint won't open**
- Check that installation completed successfully.
- Try launching it again from the Windows Start menu.
- If the issue continues, report it through the repository's Issues section.

**A file or folder won't open**
- Make sure the original file or folder still exists.
- If you moved or renamed it, add the updated location.

**I can't find the installer**
- Visit the [Releases page](https://github.com/DockMintStudio/DockMintDesktop/releases).
- Open the latest release and look under **Assets** for the Windows `.exe` installer.
