# DockMint Desktop

**A simple, customizable desktop workspace for your projects.**

DockMint Desktop helps you keep your projects, files, tasks, notes, and favorite applications organized in one place. Create separate workspaces for different activities, customize your layout, and keep the tools you use most within easy reach.

## 📥 Download DockMint

**[Go to DockMint Desktop Releases](https://github.com/DockMintStudio/DockMintDesktop/releases)**

Follow these steps to download and install DockMint on Windows:

1. Open the Releases page.
2. Select the latest available release.
3. Scroll down to the **Assets** section.
4. Download the Windows installer, usually named `DockMint-Setup-<version>.exe`.
5. Open the downloaded `.exe` file.
6. Follow the installer instructions.
7. Launch DockMint Desktop from the Windows Start menu or your desktop shortcut, if one was created.

> Only download DockMint from the official GitHub Releases page.

## ✨ Features

- **Workspaces** — Keep different projects and activities organized.
- **File & Folder Shortcuts** — Access existing files and folders without moving them.
- **Task Management** — Track your next steps and mark tasks complete.
- **Quick Notes** — Keep useful reminders and ideas close at hand.
- **Quick Launch** — Access supported application shortcuts and frequently used tools.
- **Customization** — Personalize your workspace's appearance and layout.
- **DockMint AI** — Get help with questions, planning, tasks, and notes using Local Ollama or Ollama Cloud.
- **Built-in Updates** — Check for newer versions from inside the app and choose when to download and install them.

## 🚀 Getting Started

### Create a Workspace

Create separate workspaces for school, game development, work, or personal projects.

### Add Files and Folders

Add shortcuts to files and folders you already use so you can access them from DockMint without reorganizing your existing folders.

**DockMint stores shortcuts, not copies of your files.**

Removing a shortcut from DockMint is not the same as deleting the original file.

### Manage Tasks and Notes

Use the **Tasks** panel to keep track of assignments, project milestones, bugs, and other things you need to do.

Use **Quick Notes** for ideas, reminders, and useful information.

### Set Up Quick Launch

Add supported application shortcuts to make your frequently used programs easier to open.

Only use executables and shortcuts from sources you trust.

### Customize Your Workspace

Explore the available appearance, layout, accent color, and panel settings to make DockMint work the way you prefer.

## 🤖 DockMint AI

DockMint AI is built directly into DockMint Desktop.

You can choose between two connection options:

- **Local Ollama** — Use an Ollama service running on your own computer.
- **Ollama Cloud** — Connect to Ollama Cloud using an API key.

With Local Ollama, prompts are sent to the local Ollama service you configure. With Ollama Cloud, prompts and the conversation context needed to generate responses are sent to Ollama for processing.

Cloud usage depends on your Ollama account, available models, and current usage limits. Cloud requests may consume your account's usage allowance.

## 🔒 Files and Privacy

DockMint is designed to organize access to your existing files and applications rather than replace your file system.

- Your original files remain in their existing locations.
- Removing a saved shortcut is intended to remove the link from DockMint, not delete the original file.
- Workspace information and settings are stored locally on your computer.
- DockMint AI does not have general-purpose access to browse your computer's files.
- Linking a file does not automatically send its contents to AI.
- If you use Ollama Cloud, your prompts and relevant conversation context are sent to Ollama.

No app can guarantee absolute security. Protect your Windows account and back up important files and workspace information regularly. Review the in-app Privacy Policy before using optional cloud services.

## 🔄 Updates

DockMint includes a built-in update checker.

When you open the installed app, the update status can show:

- 🟢 **UP TO DATE** — You're using the latest available version.
- 🔴 **OUT OF DATE** — A newer version is available.
- 📥 **Download latest** — Choose to download the update.
- 🔄 **Restart to install** — Confirm when you're ready to restart and install a downloaded update.

Updates are designed to give you control over when you download and install a new version.

## 🛠️ Troubleshooting

### DockMint Won't Open

- Make sure installation completed successfully.
- Try launching DockMint from the Windows Start menu.
- If the issue continues, report it through the repository's Issues section, if available.

### A File or Folder Won't Open

- Make sure the original file or folder still exists.
- If you moved or renamed it, add the updated location.

### AI Isn't Responding

- If you're using Local Ollama, make sure the Ollama service is running and the selected model is available.
- If you're using Ollama Cloud, check your connection, API key, account status, and usage limits.

### I Can't Find the Installer

1. Visit the [Releases page](https://github.com/DockMintStudio/DockMintDesktop/releases).
2. Open the latest release.
3. Look under **Assets** for the Windows `.exe` installer.

If no installer is listed, a downloadable build may not have been published for that release yet.
